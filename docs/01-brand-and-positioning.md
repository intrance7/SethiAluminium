# 01 — Brand & Positioning

## Positioning statement

Not: *"Aluminium Fabricators — Doors, Windows, Grills..."*

Instead: **"We build the spaces around you."** — Aluminium. Glass. Ceilings.
Interiors. Exteriors.

Position as an **architecture-and-fabrication studio**, not a generic local
contractor:

```
Modern Architecture  ×  Industrial Fabrication  ×  Interior Design
```

## Who the site is for (in priority order)

1. **Homeowners building/renovating** — found via Google search or referral,
   browsing on a phone in the evening, comparing 2–3 contractors.
2. **Builders / architects / contractors** who need a fabrication partner for
   a project — often on desktop, want a portfolio and process, not just photos.
3. **Shop/office owners** needing shopfronts, partitions, ACP facades.
4. **Existing customers** referring the business — need a shareable link that
   looks credible enough to forward on WhatsApp.

Design implication: the site must work as a **WhatsApp-shared link opened on
a phone in 3 seconds**, not just as a browsed desktop showcase.

## Tone of voice

- Confident, precise, understated — "precision in every frame," not hype.
- Short sentences. No stock-photo real-estate-agent language.
- Craft-forward: talk about measurement, fabrication, finishing — the actual
  process — rather than generic adjectives like "premium quality."

## Service taxonomy (6 categories — use everywhere: nav, filters, SEO)

| Category | Includes |
|---|---|
| **01 Aluminium** | Doors, windows, sliding windows, partitions, frames, custom fabrication |
| **02 Glass** | Glass doors/windows, partitions, railings, shopfronts, custom glass work |
| **03 Exterior** | ACP cladding, building facades, exterior panels, grills, gates, railings |
| **04 Interior** | False ceiling, PVC panels, wall panels, partitions, decorative panels, finishing |
| **05 Fabrication** | Custom aluminium/metal work, grills, gates, frames, structural work |
| **06 Design & Installation** | Site measurement, design, material selection, fabrication, installation, finishing |

This taxonomy drives: the "What We Build" section, the services nav dropdown,
project tags/filters, and the SEO landing page set (doc 08).

## Brand assets needed before build starts

- [ ] Business name confirmation (as it should appear — e.g. "Sethi Aluminium
      & Interiors" vs. current working name)
- [ ] Logo (SVG preferred; wordmark + icon lockup)
- [ ] Color palette (see doc 03 — proposed palette needs owner sign-off)
- [ ] Primary + secondary typefaces
- [ ] 30–50 real photos/videos of finished work, in-progress fabrication, and
      the workshop (see doc 06 asset checklist) — **this determines the
      visual direction more than anything else and should be collected before
      high-fidelity UI work starts**
- [ ] Phone number, WhatsApp number, service areas, business hours, address
      for schema/local SEO
